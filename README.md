# BTC Historical Data Research

This repository contains historical BTC trading data and step-by-step research tasks.

## Workflow

1. Pull the latest changes before starting work.
2. Only work on the task you have been assigned.
3. Read the `README.md` inside that task folder.
4. Write your solution inside the same folder.
5. Do not modify files inside `/data`.
6. Do not create fake or sample data unless a task explicitly asks for it.
7. Use Python `.py` files unless instructed otherwise.
8. Commit and push your solution after finishing.
9. Do not start the next task until instructed.

## Setup

```bash
uv sync
```

Run a solution with the project environment:

```bash
uv run python task-01-data-inspection/solution.py
```

If a task requires a new dependency, add it with `uv add <package>`.
